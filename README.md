# Worldsmith · Atelier Edition 06

## Цель v0.6: цельный атлас до 200%

Рабочие масштабы: **50 / 100 / 150 / 200%**, максимум камеры — **200%**. Леса, горы и иллюстрации POI сохраняют одну композицию. Мелкие материалы, растительность, подложки объектов и вода рисуются в координатах мира; на 150–200% они читаются лучше благодаря плотности пикселей. DPR и качество не меняют состав местности.

Земля получила разнообразную окраску и мягче настроенный рельеф; леса — вариативные группы и поляны; горы — компактные силуэты с мягкими основаниями; реки — плавные контуры. Новые миры получают дополнительные короткие тропы к достопримечательностям. Старые сохранения сохраняют географию и POI. Первый референс отсутствует в репозитории: точное визуальное совпадение с ним не подтверждено.

Инспекторы объектов и подписей поддерживают важность и диапазон видимости. Ручные подписи сохраняют размер и не скрываются автоматическим отбором. **Debug Rendering** показывает семантический уровень, физическое разрешение, макрообъекты/детали, кэш и отношение запрошенного размера к исходному. Предупреждение о пределе исходника остаётся для неподдержанных крупных иллюстраций и пользовательских изображений. 313-пиксельный фрагмент не превращается в 1500-пиксельный оригинал.

**Export → Атлас · WebP-тайлы + векторы** — дополнительный экспорт в папку Chrome/Edge. Профиль 200% × DPR 2 для ElderMar даёт верхний уровень 7200×4800, по 512 px на тайл, без огромного промежуточного холста. Есть прогресс и отмена; незавершённый пакет явно отмечается в манифесте. Доступ к папкам требует поддерживаемого браузера и HTTPS или localhost.

PNG 2K/4K/8K по-прежнему доступен для публикации; он не является источником тайлов. Ограничения, архитектура и точное разделение растровых/векторных слоёв: [SEMANTIC_ZOOM.md](SEMANTIC_ZOOM.md). Формат: [DATA_FORMAT.md](DATA_FORMAT.md). Измерения: [VALIDATION.md](VALIDATION.md).

Дополнительные проверки: `npm run test:semantic-render` (50/100/150/200%, DPR 1/2, швы), `npm run test:local-render` (локальные правки и предупреждения), `npm run test:deep-zoom` (пакет тайлов и сбой записи). `npm test` включает детерминированные проверки. Используйте `WORLDSMITH_BASE_URL` для адреса сервера, `WORLDSMITH_PLAYWRIGHT` для установленного Playwright. Пятиминутный `test:performance` проверяет рабочий диапазон до 200%; запускайте его отдельно от других браузерных тестов.

Локальная мастерская иллюстрированных фэнтезийных атласов: процедурная география, ручное редактирование, картография, игровые метаданные и экспорт.

## Запуск

Запустите **npm start** в папке проекта и откройте **http://127.0.0.1:4173** в Chrome или Edge. Иллюстрации и шрифты включены в проект; интернет для работы не требуется. Проверен запуск через HTTP; прямое открытие index.html не проверялось.

Для фоновой генерации без блокировки интерфейса рекомендуется локальный сервер: выполните **npm start** в папке проекта и откройте **http://127.0.0.1:4173**. Нужен Node.js 18+. Сервер слушает `0.0.0.0`: доступен на этом компьютере и, если разрешает сеть, по его локальному IP. Порт можно изменить переменной `PORT`.

При открытии появляется демо-мир **Элдермар**, seed `ELDERMAR-8472`, Dark Fantasy, 1800×1200. Та же карта лежит в **demo.world.json**. **example.world.json** — пример проекта старой версии для проверки совместимости.

## Новое в Atelier 05

- Отдельный render worker строит чанки и экспортные полосы. Камера перемещает кэшированную область, затем подставляется нативный LOD; SVG-подписи остаются отдельным слоем.
- Чанки по 512 физических пикселей с защитной рамкой; LRU-кэш экранных чанков ограничен 128 МиБ. Это не предел всей памяти приложения.
- Пространственный индекс для объектов, глобальные координаты лесов и гор; пересекающие границу спрайты учитываются в соседних чанках.
- Кисти объединяют pointer samples через requestAnimationFrame, интерполируют штрих и обновляют затронутую область. Один штрих — одна Undo-операция. Пустой штрих сохраняет Redo.
- Текстура поверхности привязана к координатам мира. Вода использует расстояние до берега, глубину, редкие линии течений и постепенное расширение рек.
- Performance / Balanced / Ultra сохраняют DPR. Debug Rendering показывает время кадра, чанки, кэш, границы объектов и LOD.
- Ошибка или завершение render worker корректно завершает ожидающие задания.

### Проверки редактора

`npm test` — проверки модели, редактора и worker без браузера.

`npm run test:world-render` — браузерные проверки масштаба, швов, кистей, генерации, импорта пользовательского PNG, Save/Load и экспорта PNG 2K/4K/8K.

`npm run test:performance` — пять минут нагрузки при 1920×1080 и 2300 дополнительных объектах. `WORLDSMITH_SOAK_SECONDS` меняет длительность. `WORLDSMITH_TEST_OUTPUT` задаёт папку результатов. `WORLDSMITH_PLAYWRIGHT` задаёт путь к Playwright, `WORLDSMITH_BROWSER` — путь к установленному Chromium/Chrome. При отсутствии browser override нужен браузер Playwright. `WORLDSMITH_BASE_URL` задаёт адрес тестового сервера (по умолчанию `http://127.0.0.1:4173`); при занятом порте запустите сервер с другим `PORT` и укажите этот адрес.

Если запуск отдельного браузера недоступен, откройте `http://127.0.0.1:4173/tests/browser-acceptance.html`. Первая кнопка проверяет рендер и скачивает PNG 2K/4K/8K; вторая запускает пятиминутный тест. Тестовый iframe изменяет собственный демо-мир. Проверка кэша не измеряет всю RAM или память GPU.

Точные результаты текущей проверки и ограничения — в `VALIDATION.md`. Предыдущие результаты ниже относятся к прежним итерациям.

### Свой объект за минуту

Откройте **Объекты → Импортировать объект**, выберите PNG/WebP до 5 МБ. Форма показывает рекомендации: малые объекты от 256×256, средние от 512×512, крупные от 1024×1024 px, прозрачную рамку с безопасной областью, фактические размеры и пример на карте. Максимальная сторона файла — 4096 px. Нажмите на превью для точки привязки или задайте X/Y в процентах. Заполните название, категорию, описание, размер на карте и теги, затем сохраните. Найдите объект во вкладке **Мои объекты** и нажмите на карту.

Для полной переносимости используйте Save, а не только память браузера.

Импортируются только растровые 2D-объекты. Поле assetKind и отдельный адаптер рендера оставляют место для будущих 3D-ресурсов; загрузка 3D пока не реализована.

## Основной сценарий

1. **Presets** → выберите мир. Измените Seed, размер и настройки справа. Нажмите **Generate**. **Random Seed** сразу создаёт новый мир. **New** создаёт новый seed с текущими настройками. Предыдущая карта доступна через Undo.
2. Выберите инструмент слева. Для кистей задайте радиус, интенсивность, жёсткость, плотность и вариативность. Зажмите левую кнопку и рисуйте. Height Brush поддерживает поднятие и опускание высот; Terrain Brush создаёт сушу. Для снежных гор выберите биом «Снежные вершины».
3. В панели **Объекты** выберите элемент библиотеки и нажмите на карту. Выделяйте и перетаскивайте объекты инструментом «Выбор». Инспектор меняет название, тип, иконку, описание, цвет маркера, фракцию, регион, теги, координаты и JSON-свойства.
4. Инструмент **Подписи** выбирает и перемещает текст. Нажатие на пустом участке создаёт новую подпись. В инспекторе меняются текст, размер, поворот и цвет. Ручные подписи сохраняют своё положение при автоматическом размещении остальных.
5. **Save** скачивает `.world.json`. **Load** загружает проект v1 или v2; данные v1 автоматически переводятся в новый формат.
6. **Export** → PNG или игровой JSON. PNG всегда использует Atlas Mode, полное разрешение, выбранные слои, подписи и рамку. Видимость в редакторе и включение в PNG независимы. JSON содержит все данные, в том числе скрытые слои.

Режим Editor показывает цветные маркеры и выделения. Режимы Biome, Height, Region имеют легенды. Колесо масштабирует вокруг курсора; пробел + перетаскивание или средняя кнопка перемещают карту. Миникарта открывается кнопкой карты снизу; нажатие на неё переносит область просмотра.

**Ctrl+Z** — отмена. **Ctrl+Shift+Z / Ctrl+Y** — повтор. **Delete** — удалить выбранный объект или подпись. История содержит до 25 операций с приблизительным бюджетом 64 МБ; кисти сохраняют изменения ячеек, остальные операции — снимки; она не входит в файл проекта.

## Генерация

Конвейер: domain-warped многомасштабный шум и рельеф хребтов → температура по широте и высоте → влажность → priority-flood и накопление стока → реки/слияния/озёра → климатические биомы и долины → плотность леса → поселения у воды → регионы → A* дорог с проверкой суши и склонов → мосты/броды → магические ориентиры и декоративный проход → подписи.

Параметр площади суши задаёт целевой квантиль высот. После создания озёр фактическая площадь суши может немного уменьшиться. Регионы задаются центрами с распределением по ближайшему центру. Реки используют заполненную дренажную поверхность для выхода из локальных впадин, со слабым меандрированием на суше. Это художественная география, а не физическая симуляция эрозии.

## Практические пределы

Small: 1000×700; Medium: 1800×1200; Large: 2800×1900; Custom: от 300×300 до 3200×3200. При открытии файла напрямую генерация выполняется в основном потоке; при запуске сервера — в Worker. Растеризация карты выполняется в отдельном Worker; основной поток компонует видимые чанки и обновляет камеру, SVG-подписи и инструменты.

Биомы имеют одну классификацию на ячейку. Height и Terrain образуют основу изображения, остальные слои компонуются поверх неё в сохранённом порядке. Смена рельефа вручную не запускает повторный расчёт ранее созданных рек, дорог и климата. Линии можно дорисовывать и стирать; для полной перестройки используется Generate. Положение автоподписей подбирается с оценкой размеров текста, поэтому плотные участки и вручную повёрнутые подписи могут потребовать правки.

Рисованные детали собираются из семи исходных атласов и четырёх самостоятельных мастер-ассетов с вариациями, а не генерируются нейросетью заново для каждого мира. География и метаданные при этом полностью процедурные и редактируемые. Серверы, аккаунты и облачное хранение не требуются.

Автоматически проверен запуск через HTTP. Прямое открытие file:// не проверялось: браузерная среда проверки блокирует этот тип адресов.

В комплекте: **demo-atlas.png** (с подписями и рамкой) и **demo-clean.png** (чистая иллюстрация).

Дополнительно в Atelier 03 проверены: импорт PNG с прозрачностью, редактирование метаданных, scale/rotation, повторное открытие браузера, перенос встроенного изображения в чистый браузер, пользовательские категории, удаление из коллекции с сохранением экземпляров, экспорт PNG/JSON. Базовая поверхность кэшируется при редактировании объектов; кисти автоматически обновляют кэш.
`example-custom.world.json` — переносимый пример проекта со встроенным PNG-объектом, anchor, масштабом и поворотом.


## Проверка рендера Atelier 04

Текущие результаты браузерных проверок и ограничения измерений находятся в VALIDATION.md.

Опциональный тест: установите Playwright (`npm install --no-save playwright`, затем `npx playwright install chromium --only-shell`), запустите сервер в другом терминале и выполните `npm run test:render`. Playwright не нужен для работы приложения. Можно указать путь к существующей установке через WORLDSMITH_PLAYWRIGHT.

В v0.5 Canvas 2D растеризуется в Worker: построение нового LOD и экспорт 8K всё ещё занимают время. Итоговый 8K bitmap требует значительной памяти; полосы ограничивают промежуточные изображения, но не отменяют память итогового PNG canvas. Устройство и размер окна влияют на скорость. Подробности модулей — DATA_FORMAT.md.
